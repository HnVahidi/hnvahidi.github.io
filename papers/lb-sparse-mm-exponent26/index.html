Sparse Matrix Multiplication Exponent 1.5 in the Low-bandwidth Model

Chetan Gupta, Jukka Suomela, and Hossein Vahidi

arXiv · Lean formalization

Abstract

We study sparse matrix multiplication in the low-bandwidth model: n computers multiply two n×n matrices, and each computer can send and receive one O(logn)-bit message per round. The input matrices are uniformly sparse, meaning that there are at most d nonzero entries in each row and column, and the task is to compute a uniformly sparse part of their product.

In prior work, Gupta et al.~(SPAA 2022) presented an O(d1.907)-round algorithm over fields for this problem when the sparsity structure is globally known in advance (this is referred to as the supported setting). The upper bound was later improved to O(d1.832) rounds.

In this work, we give a deterministic algorithm that solves this problem in O(d3/2) rounds in the supported setting, improving the previous bounds over fields and semirings.
